## Production Notes

**Video Format:**
- 9:16 vertical (smartphone/TikTok format)
- Filmed in natural home environments (kitchen, living room, garden)
- Parents speaking directly to camera, casual and authentic
- Minimal editing — raw emotion trumps polish

**Visual Direction:**
- Show brief b-roll of kids using app (3-4 seconds max)
- Parent's face should be primary focus
- Natural lighting, real homes, no studio setups
- Keep captions on for accessibility

**Emotional Tone:**
- Relief, pride, gratitude, hope
- Vulnerable but empowered
- "This actually works" energy
- Real struggles → real solutions

## 🎬 Production Workflow

1. **Generate videos** using the Image + Video prompts above (with AI tools like Runway, HeyGen, D-ID, etc.)
2. **Download the generated files**
3. **Optimize for web:**
   ```bash
   ffmpeg -i input.mp4 -vcodec h264 -acodec aac -b:v 2M -movflags +faststart output.mp4
   ```
4. **Extract thumbnail:**
   ```bash
   ffmpeg -i video.mp4 -ss 00:00:01 -vframes 1 -q:v 2 thumbnail.jpg
   ```
5. **Place files** in the correct folders (see above)
6. **Files are automatically loaded** via `require()` statements already configured in [landing.tsx](src/app/landing.tsx)
